## 🎨 Current Implementation

### Font Usage Strategy:
- **Titles & Headings:** Rimba Andalas font (h1, h2, h3, h4, h5, h6)
- **Body Content:** Inter font (paragraphs, regular text)
- **Fallback:** Kalam font if Rimba Andalas fails to load

### CSS Classes Available:
- `.rimba-font` - Regular Rimba Andalas
- `.rimba-bold` - Enhanced Rimba Andalas with shadow
- `.rimba-display` - Display version with effects
- `.jungle-title` - Main headings with jungle effects
- `.jungle-text` - Emphasized text with Rimba Andalas

## 🔧 Technical Details

### Font Loading:
```css
@font-face {
  font-family: 'Rimba Andalas';
  src: url('/fonts/Rimba Andalas.otf') format('opentype'),
       url('/fonts/Rimba Andalas.ttf') format('truetype');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}
```

### Fallback Hierarchy:
1. **Rimba Andalas** (primary)
2. **Kalam** (Google Fonts fallback)
3. **System serif fonts** (final fallback)
